Update the data

Open the Google Scholar profile and press Show more at the bottom until the list ends.

Option 1. Copy the page

Select the whole page (Ctrl/Cmd + A), copy it and paste it below. With the Journals' Rankings add-on on, the venue ranks come along.

Option 2. Save the page

Save it with Ctrl/Cmd + S as Webpage, Complete and load the .html file. This also brings the citations-per-year chart. Venue ranks are then carried over from the current data by title.
